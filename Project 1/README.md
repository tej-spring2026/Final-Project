# What does my portfolio analyzer do?

My portfolio analyzer conducts analysis on a given stock portfolio. It takes inputs for the user's stock tickers, number of shares owned, purchase price, and current price for whatever stock/stocks that comprise their portfolio. The application then uses these inputs to calculate the appropriate metrics and creates a portfolio summary table output showing the user's portfolio's stock allocation, best and worst performers, total portfolio return, and risk score based on portfolio diversification/concentration.
