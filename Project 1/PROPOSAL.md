 ## My Project Proposal: Stock Portfolio Analyzer

**What I'm building:** A stock protfolio analyzer which takes user inputs for a their given portfolio and produces a protfolio summary table output showing their best/worst stock performers, portfolio allocation, total portfolio return/performance, and portfolio risk score. 
**Why I chose this:** I've been very involved in the US stock market as of recent and have built up a portfolio of stock holdings. I want to be able to analyze my current portfolio and create a tool for testing how future trade executions may impact my portfolio. 
**Core features:**
- Highlight the user's best and worst performers within their stock portfolio
- Show the portfolio's stock allocation/weights using inputs of stocks held, bought-at/current stock price, and amount of shared bought
- Calculate total portfolio return to guage performance
- Produce a risk score for the porfolio by analyzing stock diversification/concentraion
**What I don't know yet:** I don't really know the most accurate way to calculate portfolio risk with only the user inputs and no external stock/S&P data retrieval. I also don't really know how to create a table containing function/calculation outputs.
