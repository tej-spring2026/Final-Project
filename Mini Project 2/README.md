# What does my earnings sentiment analyzer do?

This application takes earning call trasncripts over a series of quarters for a US public company and analyzes shifts in company sentiment through changes in CEO/admin language and tone across the quarter. This is important because many investors listen to and read earnings calls to understand the company's internal sentiment of their current status and trajectory.



# Instructions for running the application:

Simply go to your command prompt and input _______. Then copy/paste the earnings call texts from any credible source onto a word document, convert the .docx file to a .txt file, and change the file 'encoding' to UTF-8. From there just follow the commands given to upload the documents. Place as many earnings call transcripts as you'd like for your chosen company and watch the application measure shifts in language sentiment across the given periods!
