# What does this project do

This Elective Project 1 application provides AI-powered daily market briefings for a personal stock + crypto portfolio. It pulls live data from yfinance, Finnhub, and CoinGecko — feeds it to Claude Sonnet 4.6 — and aggregates real-time market data, news, analyst signals, and macro context  to delivers a sharp, six-section intelligence report on your personal stock portfolio in under 30 seconds. It also has an automated work flow which automatically pushes daily market briefings to my email at the end of each market day.
